# Devansh Grover — Portfolio (SteelCircuits)

Personal portfolio for Devansh Grover: autonomous robotics, embedded systems, AI, computer vision, and n8n automation.

Built with **React 19 + Vite**. Styling is plain CSS in `src/index.css` plus inline styles. The AI Twin chat talks to a Hugging Face Space backend (`src/services/aiTwinApi.js`), and the contact form delivers messages via FormSubmit.

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Deploy

Deploys as a standard Vite app (e.g. on Vercel): build command `npm run build`, output directory `dist`.
